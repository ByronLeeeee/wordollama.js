# Corresponding source code

The preferred form for modifying WordOllama.JS is published at:

<https://github.com/ByronLeeeee/wordollama.js>

Binary packages identify their version in the archive/file name and embedded
assembly metadata. To obtain the matching source, download the Git tag or commit
named by the release that supplied the binary. If a test build has no tag, use
the commit recorded in its build or release descriptor.

Build prerequisites and reproducible commands are documented in `README.md`.
The release scripts live in `packaging/`, and the complete automated validation
entry point is `tools/unified-smoke-test.ps1`.

If the matching source can no longer be obtained from the public repository,
contact liboyang@lslby.com and include the exact package name, version, platform,
and download source.
